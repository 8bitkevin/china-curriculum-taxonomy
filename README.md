# 中国 K12 课程知识图谱（China Curriculum Taxonomy）

一个开源的、结构化的中国 **K12（小学、初中、高中）知识图谱**：把课程拆解为细粒度的「知识点」，织成先修依赖图（DAG），并对齐国家课程标准（义务教育课程标准 2022 年版、普通高中课程标准 2017 年版〔2020 修订〕）。数据模型对齐 [Marble Skill Taxonomy (os-taxonomy)](https://github.com/withmarbleapp/os-taxonomy)，内容针对中国课程体系重新构建。

> **当前版本** `v2.4` · **知识点** 1641 · **先修边** 2272 · **课标条目** 532（18 套，codes-only）· **知识点讲解** 24（首批：小一数学上册，渐进覆盖）· **学科** 九科 K12 全学段：数学（23 册）/ 语文（23）/ 英语（20）/ 物理（8）/ 化学（7）/ 生物学（9）/ 历史（11）/ 地理（9）/ 道德与法治·思想政治（25），共 111 册，统编版与人教系教材。粒度：数学/语文逐课要素级，英语按单元句型+技能线，理科按节级核心概念，思想政治已加深到课级、历史选必已加深到单元级，地理/道法为单元级知识点（加深推进中）

## 这是什么

以统编版/人教系教材结构为骨架，将每个单元拆解为可教、可测的知识点（数学/语文为逐课要素级，其他学科为单元级知识点与核心能力级），九科 K12 全学段 111 册已全覆盖。每个知识点包含：

- **通俗描述** — 家长能看懂的一段话，说明这个知识点学什么、为什么重要；
- **掌握证据（evidence）** — 可观察的行为标准，判断孩子是否真的学会；
- **测评问法（assessmentPrompt）** — 一道可直接照着问的口头测评（`{{name}}` 为孩子姓名占位符）；
- **课标对齐** — 对应课标条目代码（义务教育 2022 版 S1–S4；高中 2017 版〔2020 修订〕H 前缀；九科各一套，均 codes-only）；
- **教材定位** — 年级（1–6 小学 / 7–9 初中 / 10–12 高中）、学期、教材版本、所属单元；
- **先修关系** — 学它之前必须/最好先学什么，每条边附一句话理由；
- **学习内容（渐进覆盖中）** — 知识点讲解、方法步骤、带解析的例题与易错提醒（`data/lessons/`，首批小一数学上册 24 个知识点，全部原创）。

### 知识点示例

> **术语说明**：面向用户一律称「知识点」。数据字段与 id 中的 `topic`（`topics.json`、`topicId`、`topicCount`、`ct_` 前缀）即知识点的机器名，不改名以免破坏下游集成；早期文档与 CHANGELOG 中的「微主题」是同一概念的历史旧称。

```json
{
  "id": "ct_g1a_22",
  "type": "PROCEDURAL",
  "subject": "数学",
  "domain": "数与代数",
  "name": "凑十法：9 加几",
  "description": "学习 20 以内进位加法的核心方法「凑十法」……",
  "grade": 1, "semester": "上",
  "evidence": ["能边摆小棒边说清 9+4 的凑十过程", "能脱离实物口算 9 加几"],
  "standards": ["csmath-2022:S1.NA.NO.06"],
  "textbook": { "publisher": "人教版", "grade": 1, "volume": "上", "unit": 8, "editionYear": 2022 }
}
```

### 先修依赖示例

```json
{ "topicId": "ct_g1b_03", "prerequisiteId": "ct_g1a_24", "strength": "hard",
  "reason": "退位减法的主算法「想加算减」依赖 20 以内进位加法熟练" }
```

`topicId` **依赖** `prerequisiteId`（先学先修，再学本体）；反转边即得「解锁」方向。

## 目录结构

```
data/
  topics.json                # 知识点（图的节点）
  dependencies.json          # 先修依赖（图的边）
  curriculum-standards.json  # 2022 版课标条目（codes-only）
  lessons/                   # 学习内容层（按学科一文件，渐进覆盖；首批 math.json）
  manifest.json              # 计数与 SHA-256 校验和
schema/                      # 上述文件的 JSON Schema
scripts/
  validate.mjs               # 零依赖完整性校验（含 DAG 无环检测）
  build-manifest.mjs         # 生成 manifest、注入 prerequisites 冗余字段
  apply-batch.mjs            # 数据批次合并工具（合并→manifest→validate 一键落库）
  report.mjs                 # 质量报告（孤岛/覆盖率/倒挂边，TOOL-2）
  dev.mjs                    # 本地开发服务器（静态托管 + 只读 API）
  fetch-textbooks.py         # 从 ChinaTextbook 仓库下载教材 PDF（本地校验用）
textbooks/                   # 教材 PDF（.gitignore，不入库）
```

## 使用

纯数据，无任何依赖，加载 JSON 即可：

```js
import topics from './data/topics.json' with { type: 'json' };
import deps from './data/dependencies.json' with { type: 'json' };

const byId = new Map(topics.topics.map(t => [t.id, t]));

// 「凑十法：9 加几」之前孩子需要先掌握什么？
const prereqs = deps.dependencies
  .filter(d => d.topicId === 'ct_g1a_22')
  .map(d => ({ name: byId.get(d.prerequisiteId).name, strength: d.strength }));

// 反过来：学好「10 以内加减法」能解锁什么？
const unlocks = deps.dependencies
  .filter(d => d.prerequisiteId === 'ct_g1a_14')
  .map(d => byId.get(d.topicId).name);
```

校验数据完整性（结构、引用、DAG、校验和）：

```bash
npm run validate
```

修改数据后重新生成 manifest（会自动维护每个知识点的 `prerequisites` 冗余字段与校验和）：

```bash
npm run manifest && npm run validate
```

## 在线浏览（viewer）

零构建静态图谱浏览器，已部署在 GitHub Pages：

> **https://8bitkevin.github.io/china-curriculum-taxonomy/viewer/**

功能：

- **图谱浏览**：按册分组的知识点列表（含入度/出度），年级/领域过滤 + 搜索；点击任一知识点查看掌握证据、测评问法（可自定义孩子姓名）、课标对齐，以及**学习路径图**——以当前知识点为中心的交互式依赖图（Canvas DAG，零依赖）：先修向左、解锁向右，连线从左向右即学习顺序（必需=实线、有益=虚线，hover 高亮世系、单击看每条边的理由、双击跳转知识点），大树按「+1 层 / 展开全部」渐进展开；原**先修链/解锁树**文字版保留为折叠的列表视图（适合复制、读屏）；`#id=ct_…` 深链可直接分享定位。
- **学习内容抽屉**：任一知识点（学习路径卡片、详情页、3D 卡片均可入口）打开页内右侧抽屉：一句话摘要、通俗讲解、方法步骤（含口诀）、例题（先想再看，解答与易错默认折叠）、易错提醒；内容按学科分批建设中（未覆盖学科显示空态与贡献指引），`#lesson=ct_…` 深链可分享；数据按学科懒加载（`data/lessons/{学科}.json`）。
- **3D 全景**：three.js WebGL（本地 vendor，零构建）渲染的深空星系视图——年级沿竖轴向上生长、四大领域成四股螺旋藤蔓；惯性拖拽旋转、滚轮缩放、搜索飞行定位；点选知识点后先修闭包橙色分层发光、解锁闭包青色发光、其余暗淡，路径节点浮现中文标签（视觉范式对标 [Marble curriculum](https://withmarble.com/curriculum/)，代码原创）。
- **质量自查**：孤岛知识点、测评问法/课标引用覆盖率、跨年级倒挂边等指标卡（口径与 `npm run report` 一致），供维护者批次合入前后对照。

本地运行与调试（推荐 `npm run dev`）：

```bash
npm run dev                # http://127.0.0.1:8787/viewer/（Ctrl+C 停止）
```

开发服务器（`scripts/dev.mjs`，零依赖）一条命令起本地环境：静态托管整个仓库（`Cache-Control: no-store`，改代码/数据刷新即得，`data/*.json` 按 mtime 热缓存）；提供与 viewer 口径一致的只读 API（CORS 全开）：`/api/summary`、`/api/topics?subject=数学&grade=1&q=凑十`、`/api/topic/ct_g1a_22`（含先修/解锁树）、`/api/standards?code=S1.NA.NO.06`。

无 Node 环境时任一静态服务器亦可：

```bash
python -m http.server 8931
# 打开 http://127.0.0.1:8931/viewer/
```

## id 与代码规则

- **知识点 id**：`ct_{学科代码}_g{年级}{a|b}_{序号}`。数学建仓最早、无学科代码前缀（`ct_g1a_22` = 一年级上册第 22 个知识点）；其余学科带拼音缩写：语文 `yw`、英语 `yy`、物理 `wl`、化学 `hx`、生物 `sw`、历史 `ls`、地理 `dl`、道德与法治/思想政治 `zz`（如 `ct_yw_g2a_03`、`ct_ls_g8a_03`）。`a`=上学期，`b`=下学期；序号在册内递增。年级统一用 1–12：1–6 小学、7–9 初中（7=初一）、10–12 高中（10=高一）。
- **课标代码**：本仓库自建的稳定代码（官方课标无条目编号），格式 `S{学段}.{领域}.{子领域}.{序号}`（义务教育 1–9 年级，S1–S4 对应四个学段）或 `H{册}.{领域}.{序号}`（高中，H1–H5 对应人教 A 版五册，stage=5），如 `S1.NA.NO.06` = 第一学段·数与代数·数与运算·第 6 条。领域代码：`NA` 数与代数、`GS` 图形与几何、`SP` 统计与概率、`IP` 综合与实践。详见 `data/curriculum-standards.json` 的 `codeScheme`。

## 数据来源与版权（重要）

- **教材**：单元结构以人教版/统编版教材（2022 课标版等）为骨架整理。教材 PDF 版权属于人民教育出版社等出版社，本仓库**不收录、不再分发**任何教材内容；`textbooks/` 目录已被 gitignore，仅供本地目录核对。
- **课标**：课程标准条目采用 **codes-only** 策略——只存自建代码与自拟极简标题，不收录课标原文。义务教育学段（1–9 年级）以《义务教育课程标准（2022 年版）》为准（[教育部官方发布](http://www.moe.gov.cn/srcsite/A26/s8001/202204/t20220420_619921.html)）；高中学段（10–12 年级）以《普通高中课程标准（2017 年版 2020 修订）》为准。
- **本图谱数据**（知识点名称/描述/证据/测评问法、依赖理由、讲解与例题等原创内容）：以 CC BY-SA 4.0 发布，转载需署名并相同方式共享。讲解与例题均为自建原创（D-030），不搬运教材原文、教辅或真题。
