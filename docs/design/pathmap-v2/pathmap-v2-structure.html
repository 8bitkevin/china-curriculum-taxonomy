学习路径图 v2 · 结构蓝图

以学生三问组织路径视图：我在哪、先学什么、学完通向哪里。保留 2026-10 非对称模型（来路＝必需路由、去路＝一跳解锁＋通向计数），新增旅程坐标：起点锚、当前站、学段里程碑门与学期游标，视觉语言对齐出版级规范（1px 细线、零阴影、品牌绿只标焦点）。

用户三问 → 设计映射

  • 我在哪 —— 当前知识点是全图唯一品牌绿焦点，学期热条上的游标格与之联动，位置始终一望可知
  • 先学什么 —— 来路只保留必需先修主线（玫红），站序即学习顺序；有益先修挂一跳叶子不递归
  • 通向哪里 —— 去路一跳直达，远期影响压缩为热条计数；学段里程碑与目标锚给出终点方向

行业对标

  • Duolingo —— 路径主线隐喻与唯一「下一步」焦点，降低选择成本
  • Khan Academy —— 节点状态语言（未学 / 在学 / 掌握 / 薄弱）为进度层预留
  • roadmap.sh —— 阶段分组与前置可见，学习顺序不靠图例硬读
  • 保留本仓 2026-10 非对称模型：来路路由、去路计数，不做全闭包蜘蛛网

落地要点

  • 视觉：去阴影改 1px 细线描边，色彩只编码数据，品牌绿只作焦点
  • 结构：新增起点锚 / 学段门 / 学期游标三类旅程坐标（数据已有，纯渲染层）
  • 布局：保留自研学期泳道 × 依赖列，主线沿对角线贯穿
  • 详情侧卡从浮层升级为常驻栏，讲解与练习（lessons）入口前置
