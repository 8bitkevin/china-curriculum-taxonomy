## 2. 多学科数据口径（D-016）

1. **学科代码与 id**：`ct_{code}_g{年级}{a|b}_{序号}`，code：语文 `yw`、英语 `yy`、物理 `wl`、化学 `hx`、生物学 `sw`、历史 `ls`、地理 `dl`、道法/政治 `zz`。数学沿用 v1.0 历史格式（`ct_g{年级}{a|b}_{序号}`，id 冻结不动）。
2. **subject 取值**：数学 / 语文 / 英语 / 物理 / 化学 / 生物学 / 历史 / 地理 / 道德与法治（小学+初中）/ 思想政治（高中）。
3. **publisher**：统编三科（语文、道法/政治、历史）记「统编版」（教育部组织编写、人教社出版）；其余记「人教版」。validate 白名单扩为 人教版/人教A版/统编版。
4. **domain 按学科受控**（schema 放开为 string，validate 按 `DOMAIN_BY_SUBJECT` 校验，替代数学时代的全局四领域枚举）：

| 学科 | 领域 |
|---|---|
| 数学 | 数与代数 / 图形与几何 / 统计与概率 / 综合与实践（沿用） |
| 语文 | 识字与写字 / 阅读与鉴赏 / 表达与交流 / 梳理与探究（2022 课标四大语文实践活动；拼音入识字与写字，文言、名著入阅读与鉴赏，写作、口语交际入表达与交流） |
| 英语 | 语音 / 词汇 / 语法 / 听说 / 阅读 / 写作 |
| 物理 | 力学 / 热学 / 声与光 / 电与磁 / 能量与能源 / 近代物理 / 实验与探究 |
| 化学 | 化学实验与探究 / 无机物及其应用 / 物质结构与性质 / 化学反应原理 / 有机化学基础 / 化学与社会 |
| 生物学 | 分子与细胞 / 生物体的结构层次 / 植物的生活 / 人体生理与健康 / 生物的多样性 / 遗传与进化 / 稳态与调节 / 生物与环境 / 生物技术与工程 |

| 思想政治 | 中国特色社会主义 / 经济与社会 / 政治与法治 / 哲学与文化 / 当代国际政治与经济 / 法律与生活 / 逻辑与思维 |

5. **高中册名与学期映射**（validate `HS_BOOKS_BY_SUBJECT`，册名必填；「通行教学进度，映射为约定」同 D-014）：
   - 语文：必修上册 10 上 / 必修下册 10 下 / 选择性必修上册 11 上 / 中册 11 下 / 下册 12 上

6. **年龄带宽**：全库统一 `ageRangeStart = grade + 5`、`ageRangeEnd = grade + 6`（与数学一致）。
7. **版次口径**（沿 D-014）：`editionYear` = 本地基线 PDF 版次年；版权页可读则取「第 X 版」年，乱码/无版次行的按目录结构 + 公开版次判别（如初中物理 2012 版「第一章 机械运动」结构）。跟版待办同 D-006。
8. **schemaVersion**：topics 模型因 domain 全局枚举放开为按学科受控，topics.json `schemaVersion` 1→2（结构兼容：老数据不动、新学科加入；迁移说明见 CHANGELOG）。dependencies/curriculum-standards 模型未变。

## 4. 版本号与批次（沿 D-008：一册一 commit）

数据 version 逐册 minor +1：语文 23 册 = v1.1.0 … v1.23.0；英语 20 册 = v1.24.0 … v1.43.0；物理 8 册 → v1.51.0；化学 7 册 → v1.58.0；生物学 9 册 → v1.67.0；历史 11 册 → v1.78.0；地理 9 册 → v1.87.0；道法/政治 25 册 → v2.0.0（全学科完成）。每科课标批次并入该科首册 commit（数学 v0.2.0 独立成批的先例改为随首册合入，减少空 commit）。

主题密度口径（对齐数学 25–35/册 及教材实际容量）：

- 小学语文 ≈ 22–30/册（拼音/识字/阅读要素/口语/写话）；初中语文 ≈ 18–26/册（阅读+文言+写作+综合）；高中语文 ≈ 14–20/册（任务群+文言+写作）
- 小学英语 ≈ 14–20/册（单元话题词汇+核心句型+语音）；初中 ≈ 18–24/册；高中 ≈ 12–18/册
- 初中理化 ≈ 22–28/册；初中生物/地理/历史 ≈ 18–26/册；高中理科 ≈ 14–22/册
- 道法小学 ≈ 10–14/册（单元主题+活动要素）；初中道法 ≈ 14–20/册；高中政治 ≈ 10–16/册

合计预估 ≈2600 新主题、≈4200 新边、≈450 新课标条目。

## 5. 每册工作流（固定循环，同数学 M3–M6）

1. `python scripts/extract-toc.py <册名>` 生成/校验单元基线（新学科卷册表已扩入；扫描版或乱码目录 → 人工基线 `source: "manual"`，从公开目录结构整理）
2. 起草批次片段 `.ct-batches/{subject}-{grade}{sem}.json`（topics + edges + 首册含课标套）
3. `node scripts/apply-batch.mjs <片段>`（合并 + manifest + validate）
4. `node scripts/report.mjs` 检查：孤岛 0 / assessmentPrompt 100% / 课标引用 ≥95% / 倒挂边 0
5. commit（`feat(data): 语文一年级上册 N 个微主题 + 先修边（Y1-1）` 等）

依赖边只建同学科边（跨学科先修关系如「物理计算依赖数学比例」暂不建图，记入远期 backlog，避免边爆炸与跨科倒挂噪音）。

## 6. 跨学段衔接链专项（每科收尾退出条件）

- 语文：拼音→识字→默读浏览→文言实词虚词→古代诗文鉴赏→整本书阅读；看图写话→段篇习作→记叙/说明/议论→思辨性写作
- 英语：字母语音→话题词汇→核心句型→时态语态→从句→语篇读写
- 物理：声光热现象→测量与运动→力电磁→能量守恒→动量/场论观念（高中）
- 化学：物质变化现象→元素化合物→微粒观→反应原理→有机结构
- 生物：细胞→生物体→遗传进化→稳态调节→生态→生物技术
- 历史：时序观念→中国古近现→世界古近现→专题贯通（制度/经济/文化）
- 地理：地球地图→世界中国区域→自然人文系统→区域发展→资源环境安全
- 道法/政治：自我与规则→道德法律→国情制度→思政理论体系

## 7. 质量与复核口径（如实声明，同数学计划 §8）

机器校验全绿（validate + report 四指标）是每册合入硬门槛；CONTRIBUTING 的人工复核（每册 ≥20% 通读）不由本会话替代，CHANGELOG 按科标注「机器校验全绿，人工抽读待办」。codes-only 不变量不破坏；PDF 不入库（D-004）。
