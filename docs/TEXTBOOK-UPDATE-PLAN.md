## 1. 背景与目标

- 官方依据《义务教育课程标准（2022 年版）》修订的新教材三年铺开：2024 秋一/七年级 → 2025 秋二/三/八年级 → **2026 秋全年级覆盖**。当前学年在校生已全部使用新教材。
- 本仓库旧基线实为 **2011 课标版教材**（数学/理科 2012-2014 版、统编 2016-2018 旧版）；小学数学 `editionYear:2022` 为错标。高中为 2019 版（现行最新，**不动**）。
- 教材源已切换**国家中小学智慧教育平台**（官方电子教材，`scripts/fetch-textbooks-smartedu.py`，认证通道见 §8）。
- **目标**：九科（数学/语文/英语/物理/化学/生物学/历史/地理/道德与法治·思想政治）义务段 **1250 点**全部整册切换新版（`editionYear` = 官方启用批次年 2024/2025/2026），教材题册页可回翻核对；知识点 id / 图谱结构 / 课标 codes 不动。

## 5. 新旧教材结构性差异备忘（策展时的已知迁移）

策展 `remap-2026.json` 前必读：新版教材大量**跨册/跨年级重组**，已确认的迁移路线（B-NE1 实证）：

- 数学：100 以内笔算→一下第 5 单元；角→三上「线和角」；观察物体→三上；分类与整理→二上；认识人民币→一下「欢乐购物街」；倍/万以内加减→二下；认识时间/时分秒/钟表→二下「时间在哪里」；周长与长方形正方形→三下；位置与方向→四上「寻找宝藏」；年月日→「年、月、日的秘密」；公顷→五上多边形的面积；数对位置→六上「确定位置」；简易方程→「用字母表示数和数量关系」；代数式独立成章（七上）；初中章号整体重排（七下 5-10→7-12、八下 16-20→19-24、九上 21-25→25-30，圆拆「圆/直线与圆」，反比例函数九下→九上，概率初步→九下）。
- 统编语文：低年级块结构（识字/汉语拼音/课文）改编号单元制；一上「位置」「认识钟表」类单元取消；单元主题词常在目录中独立成行。
- 无编号主题单元（extract-toc 已支持）：数学游戏 / 欢乐购物街 / 时间在哪里 / 数学连环画 / 年、月、日的秘密 / 1亿有多大 / 寻找宝藏 / 我上学了。
- 挂起先例：新版暂无对应的旧单元（比、扇形统计图、植树、优化、集合、找规律、克与千克、推理、概率初步、除数是两位数的除法）→ 保留旧锚 + `deferred` 登记，不得强行锚定。

跨册迁移的**内容验证方法**：以旧单元知识点名称中的特征词（术语/例题特征）在新版 PDF 全文检索（PyMuPDF），命中页落在目标单元页域方可确认；纯标题相似度不足为凭。

## 6. 每批标准工序（SOP）

以「册」为最小切换单位，批内逐册完成 1-8，全部册次完成后 9-10：

1. **到货确认**：`python scripts/fetch-textbooks-smartedu.py <册名...>`（幂等；token 失效先找用户重取）。
2. **基线提取**：`python scripts/extract-toc.py <册名...>`；质检三关——`--check` sha 对齐、0 单元/异常单元数扫描、抽 1-2 册人工对照目录页原文。manual 旧基线在新 PDF 到货后**必须删除重提**（旧 manual 描述旧版）。
3. **diff 底稿**：确认 `.scratch/old-textbook-units/` 有该册旧快照后跑 `node scripts/diff-textbook-units.mjs <册名...>`。
4. **remap 策展**：为每册写 `units` 映射（跨册用 `{stem, unit}`）+ `topics` 逐点覆盖（单元拆分时）+ `deferred`（新版暂无对应）+ `editionYear`（批次年）。依据：§5 备忘 + diff 底稿 + 特征词全文检索验证。**映射必须全覆盖**：旧 unit 键要么映射、要么在 deferred，不得静默遗漏。
5. **dry 检查**：`node scripts/apply-textbook-remap.mjs --dry`——零 warning 才继续；warning=映射缺口。
6. **落盘**：去掉 `--dry` 正式执行（topics + lessons 成对更新，跨年级联动 grade/semester/ageRange）。
7. **教材题重定位**：`python scripts/relocate-exercise-pages.py <册名...>`（命中改写 P 页码；未命中自动标「·页码待复核」并记 `.scratch/relocate-misses.json`）。
8. **抽验**：每册抽 3 处 label 回翻新 PDF 核对页码；抽 3 个跨册迁移点核对锚定合理性。
9. **校验提交**：`npm run manifest && npm run validate` 全绿 → commit（数据+基线+remap 表+工具改动分文件列出）。
10. **状态同步**：本方案 §4 批次表打勾、CHANGELOG 批次条目、（若有）DECISIONS 增补。

## 7. 验收标准

- **每批**：validate + manifest 全绿；批内册次 `editionYear` 全部为批次年（deferred 点除外且已在 remap 登记）；`lesson.source.unit === topic.textbook.unit` 100%；重定位结果与待复核清单落档；抽验零失真。
- **全局（T-2 完成后）**：1641 点 `editionYear` ∈ {高中 2019/2020，义务 2024/2025/2026} 或有登记的挂起说明；「页码待复核」清零；README 统计与基线表同步；全库无新旧混编册。

## 8. 风险与操作注意

| 项 | 处置 |
|---|---|
| 平台风控 | 下载并发 ≤2；403 后长静默冷却（30-300s 脚本内置）；脚本幂等可随时续传 |
| token 过期 | 认证失败（401）时请用户登录 basic.smartedu.cn 重取 UC_TOKEN cookie 值（脚本自动取内层 access_token） |
| 解析器新版权式 | 先查本方案 §5 与 extract-toc 的 SPECIAL_UNITS/模式注册表；新式样按既有先例扩 regex，改完必须用至少 3 册回测（含 1 册旧式）防回归 |
| 高中 manual 基线 | 高中数学必修一/选必一二的 manual 基线是**现行版合法人工整编，不可删**（历史教训：哈希对账时曾误删，已恢复） |
| 对账口径 | 基线↔PDF 一律用真实文件哈希对算（hashlib）；`.scratch/smartedu-report.json` 的 sha 会被 list 模式覆盖，不可作对账依据 |
| AOCI | 数据/文档改动后待 MCP 会话补 `aoci_maintain`；执行 run 开始时先 `aoci_rules`→`aoci_overview` 加载认知 |
