## 1. 背景与目标

- 官方依据《义务教育课程标准（2022 年版）》修订的新教材三年铺开：2024 秋一/七年级 → 2025 秋二/三/八年级 → **2026 秋全年级覆盖**。当前学年在校生已全部使用新教材。
- 本仓库旧基线实为 **2011 课标版教材**（数学/理科 2012-2014 版、统编 2016-2018 旧版）；小学数学 `editionYear:2022` 为错标。高中为 2019 版（现行最新，**不动**）。
- 教材源已切换**国家中小学智慧教育平台**（官方电子教材，`scripts/fetch-textbooks-smartedu.py`，认证通道见 §8）。
- **目标**：九科（数学/语文/英语/物理/化学/生物学/历史/地理/道德与法治·思想政治）义务段 **1250 点**全部整册切换新版（`editionYear` = 官方启用批次年 2024/2025/2026），教材题册页可回翻核对；知识点 id / 图谱结构 / 课标 codes 不动。

## 6. 每批标准工序（SOP）

以「册」为最小切换单位，批内逐册完成 1-8，全部册次完成后 9-10：

1. **到货确认**：`python scripts/fetch-textbooks-smartedu.py <册名...>`（幂等；token 失效先找用户重取）。
2. **基线提取**：`python scripts/extract-toc.py <册名...>`；质检三关——`--check` sha 对齐、0 单元/异常单元数扫描、抽 1-2 册人工对照目录页原文。manual 旧基线在新 PDF 到货后**必须删除重提**（旧 manual 描述旧版）。
3. **diff 底稿**：确认 `.scratch/old-textbook-units/` 有该册旧快照后跑 `node scripts/diff-textbook-units.mjs <册名...>`。
4. **remap 策展**：为每册写 `units` 映射（跨册用 `{stem, unit}`）+ `topics` 逐点覆盖（单元拆分时）+ `deferred`（新版暂无对应）+ `editionYear`（批次年）。依据：§5 备忘 + diff 底稿 + 特征词全文检索验证。**映射必须全覆盖**：旧 unit 键要么映射、要么在 deferred，不得静默遗漏。
5. **dry 检查**：`node scripts/apply-textbook-remap.mjs --dry --table <本批过滤表>`——零 warning 才继续；warning=映射缺口。累计表条目随批次消费，直接重放累计表会对已切换册次报警，故每批用仅含本批册次的过滤表执行（如 `.scratch/remap-bne2.json`），策展条目合并回累计表存档。
6. **落盘**：去掉 `--dry` 正式执行（topics + lessons 成对更新，跨年级联动 grade/semester/ageRange）。
7. **教材题重定位**：`python scripts/relocate-exercise-pages.py <册名...>`（命中改写 P 页码；未命中自动标「·页码待复核」并记 `.scratch/relocate-misses.json`；可多册一次调用——缓存合并落盘；书前偏移由页脚印刷页码直读校准，不再依赖目录探测）。
8. **抽验**：每册抽 3 处 label 回翻新 PDF 核对页码；抽 3 个跨册迁移点核对锚定合理性。
9. **校验提交**：`npm run manifest && npm run validate` 全绿 → commit（数据+基线+remap 表+工具改动分文件列出）。
10. **状态同步**：本方案 §4 批次表打勾、CHANGELOG 批次条目、（若有）DECISIONS 增补。

> **2026-11-06 重定位工具修正注**：B-NE2 抽验发现并修复四处缺陷——① 书前偏移探测失败时静默回退默认 4，与页脚实测值（语文/小学数学一律 5、初中数学 7）不符，命中页系统性偏 1-2 页；② 低年级注音把 CJK 连串打断、单元范围键汉字序号与阿拉伯数字失配，匹配与 ±3 守卫双双失效；③ 多册一次调用时后册用磁盘旧状态覆盖前册改动，仅末册真正落盘；④ 早期坏页码「P-1」无法再被 `P(\d+)` 解析，相关题永久跳过。修复后对全部 24 册重算并修正 B-NE1 册次标签；抽验（一下 P27/二上 P55/六上 P50）与页脚真值一致。
