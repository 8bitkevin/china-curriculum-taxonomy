- **D-031 学习内容原则修订：教材对齐优先 + 扩展加深，新增练习层**（2026-10-26，用户决策）— 教材是权威与基础（公开知识）：讲解必须覆盖对应教材单元的核心知识（定义/法则/术语/方法表述与教材对齐），并在教材之上做通俗化与加深扩展；练习题教材优先采用（教材例题/练习题的题型与数据保留，题干表述规范化重写并标注册·页·题号），再加变式与扩展题。替代 D-030 的「自建原创、不搬教材原文」条款。边界不变：D-004 教材 PDF 仍仅本地参考、不入库不分发；教材原句不整段照抄，课文/语篇原文（语文英语）不收录；单元素材卡属中间工作稿不入库。数据层升级 lessons schema v2：lesson 级 `source` 对齐标记 + `exercises[]`（kind: textbook/variant/extension + 题级 `source` 页码题号标注），向后兼容、渐进覆盖；全库补齐方案与分批 SOP 见 `docs/LESSONS-ROLLOUT-PLAN.md`。【「不整段照抄、课文/语篇原文不收录」边界已被 D-032 修订，其余仍有效】
- **D-032 语文/英语课文原文收录解禁：教材对齐原则全学科统一**（2026-10-26，用户决策）— 教材是国家公开发行的课程资源，内容必须基于原版教材；D-031 对语文/英语「课文/语篇原文一律不收录」的特别边界废止，两科与其他学科统一：课文/语篇原文可直接收录为讲解素材与练习语料（诗句、课文段落、生字词、语篇按原文命题），收录处与其他学科一致标注册·页。全科表达规范由「不整段照抄教材原文」改为「讲解以重述为主，直接引用教材原文（定义/法则/课文语句等）时标注来源」。D-004 教材 PDF 文件不入库、不分发条款维持有效——整本 PDF 的分发与教材内容的收录是两回事。README 数据来源声明同步区分：图谱原创内容 CC BY-SA 4.0，收录的教材原文权利归出版社/原作者，不因入库改变归属。【引用的页码标注已被 D-033 移到数据层】
- **D-033 讲解表述去教材化：用户可见文本不提来源**（2026-10-27，用户决策）— 讲解、练习题干/选项/答案/解析、方法、易错等一切用户可见文本只讲知识本身，不出现「教材」「书pN/第N页」页码、例题编号（例1）、栏目名（做一做/你知道吗/整理和复习/成长小档案等）、「本单元/上册/下册」等教材组织信息——用户只关心知识点本身，不关心来源。内容仍以教材为准（D-031 对齐要求不变），来源标注退到**数据层**：lesson 级 `source` 与题级 `source.label`（册·页·内容描述）保留为可翻书核对的维护者凭证，validate 强制校验不变；viewer 不再渲染题级出处，练习分类徽标「教材题」文案改「同步」（kind 数据值不动）。语文/英语直接引用的课文原文（D-032）同样不在正文标页码，页码记入数据层 source。已落库 173 点全量清理完成。
